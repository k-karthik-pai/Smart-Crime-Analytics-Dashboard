Required fields & import rules

Required: District_Name, FIR_Year, FIR_Stage, UnitName.

Optional nonnegative counts: Male, Female, Boy, Girl, Accused_Count, Arrested_Count. Optional: FIR_Type, Latitude, Longitude. Leave unknown values blank; they are not treated as known zeroes. Coordinates must be a valid pair.

Use one row per FIR, not one row per victim or accused. Repeated analysis rows are kept because different FIRs can share these fields; a warning asks you to check duplicates. This app cannot verify a file's provenance or completeness. Import only records you are authorized to analyze.
