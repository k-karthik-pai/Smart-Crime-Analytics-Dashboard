# Synthetic district test data

DEMO-SYNTHETIC-district-data.csv contains 153 entirely fictional FIR rows, three fictional districts, and years 2022–2024. All counts, case stages, and coordinates are invented for software testing; coordinates are arbitrary map positions and do not describe real incidents or police stations. Never use this file as evidence or combine it with real crime statistics.

Upload the CSV through District Analysis. North has 12, 18, 24 rows (+33.3% in 2024); Central has 24, 18, 12 (-33.3%); South has 15 each year (0%). Blank optional values deliberately test missing-data handling. Some records lack coordinates.

This optional example is excluded from the website build and is never automatically loaded. Existing metro figures are unchanged.
